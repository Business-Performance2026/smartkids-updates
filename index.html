جاهز؟ وصّل الشاشة ثم اضغط تثبيت

يستغرق التثبيت حوالي دقيقة

هذا المتصفح لا يدعم التثبيت. افتح هذه الصفحة في Google Chrome أو Microsoft Edge على كمبيوتر.
يجب فتح الصفحة من رابطها على الإنترنت (https).

الخطوات

  1. افتح هذه الصفحة في Chrome أو Edge على كمبيوتر (لا تعمل على الجوال).
  2. وصّل الشاشة بالكمبيوتر بكيبل USB-C يدعم نقل البيانات.
  3. اضغط تثبيت، واختر من القائمة المنفذ الذي ظهر (غالباً اسمه USB أو COM) ثم Connect.
  4. اضغط Install ثم Install مرة أخرى للتأكيد، وانتظر حتى يكتمل الشريط. لا تفصل الكيبل.
  5. عند ظهور Installation complete اضغط زر RST خلف الشاشة، فيظهر شعار مبتكر ثم شاشة الإعداد.

إذا لم يتصل أو لم يظهر المنفذ

  1. جرّب كيبلاً آخر، فبعض الكيابل للشحن فقط.
  2. اضغط مطوّلاً زر BOOT خلف الشاشة، واضغط RST مرة واحدة، ثم اترك BOOT، وأعد الضغط على تثبيت.
  3. أغلق أي برنامج آخر يستخدم الشاشة (مثل VS Code أو Arduino) ثم حاول مرة أخرى.
ملاحظة: التثبيت من هذه الصفحة يمسح بيانات الشاشة (الاسم والمهام والنجوم) ويبدأ من جديد. لتحديث شاشة مستخدمة استعمل: الإعدادات ← التحديثات.
English: Open this page in Chrome or Edge on a computer, plug the screen in with a USB-C data cable, press the green button, choose the port, then Install. When it says “Installation complete”, press RST on the back. If the port does not appear: hold BOOT, press RST once, release BOOT, and try again.
